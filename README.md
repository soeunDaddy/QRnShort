# 🚀 SmartHub: QR Studio & ShortLink Studio

QR 코드 생성 및 초고속 OpenAPI URL 단축 기능을 제공하는 올인원 웹 애플리케이션 프로젝트입니다.

---

## 📌 주요 기능 및 특징

1. **상호 전환 네비게이션 ('QR코드' & 'URL단축' 버튼)**
   - 상단 헤더의 네비게이션 탭을 통해 QR 코드 생성기와 URL 단축기를 자유롭게 전환할 수 있습니다.
   - 루트 `index.html` 통합 허브를 통해 두 기능의 상세 소개 및 바로가기 카드를 제공합니다.

2. **스마트 QR 코드 생성기 (`url2qr`)**
   - URL 및 텍스트 입력 시 실시간 고해상도 QR 코드 생성
   - 클릭 한 번으로 고화질 JPG 이미지 자동 다운로드 (`1000x1000` 해상도)
   - URL 단축기에서 넘겨받은 쿼리 파라미터(`?url=...`) 자동 감지 및 즉시 QR 변환

3. **스마트 URL 단축기 (`urlShort`)**
   - **URL 입력창**: 단축할 긴 링크를 편리하게 입력 (클리어 버튼 포함)
   - **버튼 비활성화 검증**: 입력 필드가 비어있으면 '단축하기' 버튼이 자동으로 비활성화
   - **OpenAPI 실시간 단축**: OpenAPI(is.gd, v.gd JSONP 및 다계층 Fallback)를 통해 1초 만에 단축 URL 생성
   - **읽기 전용 출력 상자**: 생성된 단축 URL을 안전하게 표시하는 `readonly` 상자
   - **원클릭 복사 및 알림**: '복사' 버튼 클릭 시 클립보드에 자동 복사되고 `'복사하였습니다'` 알림창 표시
   - **QR 코드 연동**: 단축된 URL을 즉시 QR 코드로 변환하는 원클릭 바로가기 버튼 제공
   - **최근 단축 기록**: 로컬 스토리지 기반 최근 단축 링크 저장 및 관리

## 💻 실행 방법

웹 브라우저(Chrome, Edge, Safari 등)에서 `index.html`, `url2qr/index.html`, 또는 `urlShort/index.html`을 더블 클릭하여 바로 실행할 수 있습니다.
별도의 백엔드 설치 없이 모든 기능이 브라우저에서 즉시 동작합니다.
